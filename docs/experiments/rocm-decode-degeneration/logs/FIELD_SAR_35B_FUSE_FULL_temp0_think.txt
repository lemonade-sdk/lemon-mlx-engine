**Maxwell's equations** are a set of four fundamental partial differential equations that describe how electric and magnetic fields are generated, interact, and propagate through space. Formulated by Scottish physicist **James Clerk Maxwell** in the 1860s, they unified the previously separate theories of electricity, magnetism, and optics into a single coherent framework: **classical electromagnetism**.

---

### 🔹 The Four Equations (in vacuum)

Below is the differential form (most common in modern physics), along with their names, mathematical expressions, and physical meanings:

| # | Name | Equation | Physical Meaning |
|---|------|----------|------------------|
| 1 | **Gauss's Law for Electricity** | `∇ · E = ρ / ε₀` | Electric charges produce electric fields. The divergence of **E** at a point is proportional to the charge density `ρ` there. Field lines start on positive charges and end on negative ones. |
| 2 | **Gauss's Law for Magnetism** | `∇ · B = 0` | There are no magnetic monopoles. Magnetic field lines always form closed loops; they never begin or end at a point. |
| 3 | **Faraday's Law of Induction** | `∇ × E = −∂B/∂t` | A changing magnetic field induces a circulating electric field. This is the principle behind electric generators and transformers. |
| 4 | **Ampère–Maxwell Law** | `∇ × B = μ₀J + μ₀ε₀ ∂E/∂t` | Magnetic fields are produced by electric currents (`J`) **and** by changing electric fields. Maxwell's addition of the `∂E/∂t` term (called the *displacement current*) was the crucial insight that completed the theory. |

**Symbols:**
- `E` = electric field vector
- `B` = magnetic field vector
- `ρ` = electric charge density
- `J` = electric current density
- `ε₀` = vacuum permittivity
- `μ₀` = vacuum permeability
- `∇·` = divergence, `∇×` = curl, `∂/∂t` = partial time derivative

---

### 🔍 What These Equations Reveal

1. **Electricity and magnetism are two sides of the same coin.**  
   Changing electric fields create magnetic fields, and changing magnetic fields create electric fields. This mutual induction allows self-sustaining waves to propagate through empty space.

2. **Prediction of electromagnetic waves.**  
   Combining the equations yields a wave equation for `E` and `B` traveling at speed:  
   `c = 1 / √(μ₀ε₀)`

3. **Unification of physics.**

**Fourier analysis** is a mathematical framework for decomposing complex functions or signals into simpler, periodic components (sines and cosines, or complex exponentials). It is one of the most powerful and widely used tools in science, engineering, and data science because it reveals the **frequency content** hidden in time-domain data.

---

### 🔍 Core Intuition
Imagine listening to a chord on a piano. Your ear naturally separates it into individual notes (frequencies) and their relative loudness. Fourier analysis does exactly that mathematically:
- **Time domain**: How a signal changes over time (e.g., voltage vs. time, sound pressure vs. time).
- **Frequency domain**: Which frequencies are present and how strong each one is.

Fourier analysis provides the bridge between these two views.

---

### 📐 Mathematical Foundations

#### 1. **Fourier Series** (Periodic Functions)
Any periodic function `f(t)` with period `T` can be written as an infinite sum of sines and cosines (or complex exponentials):
```
f(t) = a₀ + Σ [aₙ cos(nω₀t) + bₙ sin(nω₀t)]
```
or more compactly using Euler's formula:
```
f(t) = Σ cₙ e^(i n ω₀ t)
```
where `ω₀ = 2π/T` and coefficients `cₙ` are found by projecting `f(t)` onto each exponential basis function.

#### 2. **Fourier Transform (FT)** (Aperiodic/Finite-Energy Functions)
For non-periodic signals, we replace the sum with an integral:
```
F(ω) = ∫_{-∞}^{∞} f(t) e^(-iωt) dt   (Forward FT)
f(t) = (1/2π) ∫_{-∞}^{∞} F(ω) e^(iωt) dω   (Inverse FT)
```
`F(ω)` is the **frequency spectrum** of `f(t)`. The FT is essentially a continuous change of basis in function space.

---

### ⚙️ Why It Works: Key Mathematical Insights
- **Orthogonality**: Complex exponentials `e^(iωt)` are orthogonal over infinite intervals. This allows unique, stable extraction of each frequency component.
- **Linearity**: The FT is a linear operator. Superposition holds: `FT{af + bg} = a·FT{f} + b·FT{g}`.
- **Convolution Theorem**: Convolution in time ↔ multiplication in frequency:
  `FT{f * g} = F(ω)·G(ω)`
  This turns differential/integral equations into algebraic ones.
- **Parseval's Theorem**: Energy is conserved across domains:
  `∫|f(t)|² dt = (1/2π) ∫|F(ω)|² dω`

---

### 💻 From Theory to Practice: DFT & FFT
Real-world signals are sampled, so we use the **Discrete Fourier Transform (DFT)**:
```
X[k] = Σ_{n=0}^{N-1} x[n] e^(-i 2πkn/N)
```
- **Naive DFT**: `O(N²)` operations → too slow for large `N`.
- **Fast Fourier Transform (FFT)**: A divide-and-conquer algorithm that computes the DFT in `O(N log N)` time. Invented in 1965 (Cooley-Tukey), it powers modern signal processing, imaging, and communications.

---

### 🌍 Major Applications
| Field | Use Case |
|-------|----------|
| **Signal Processing** | Audio filtering, radio modulation, noise reduction, spectral analysis |
| **Image Processing** | JPEG compression (DCT is a variant), edge detection, frequency-domain filtering |
| **Physics & Engineering** | Solving PDEs (heat, wave, Schrödinger equations), optics (diffraction), quantum mechanics |
| **Data Science** | Time-series forecasting, pattern recognition, anomaly detection, machine learning (Fourier features) |
| **Medicine** | MRI reconstruction (k-space is a Fourier domain), EEG/ECG analysis |

---

### ⚠️ Limitations & Modern Extensions
- **Stationarity assumption**: Standard FT assumes the signal's frequency content doesn't change over time.
  → **Short-Time Fourier Transform (STFT)** & **Wavelet Transform** fix this by analyzing local frequency content.
- **Fixed resolution**: FT gives exact frequencies but poor time localization (and vice versa).
  → **Heisenberg-Gabor uncertainty principle**: `Δt · Δω ≥ 1/2`. You can't know both time and frequency perfectly.
- **Non-linear/non-stationary signals**: Require tools like Hilbert-Huang transform, empirical mode decomposition, or deep learning.

---

Fourier analysis is the **language of frequencies**. It transforms problems that are intractable in the time domain into elegant algebraic or geometric problems in the frequency domain. Its mathematical purity, computational efficiency (via FFT), and physical universality make it indispensable across virtually every quantitative discipline.

The **Doppler effect** (or Doppler shift) is the change in frequency (or wavelength) of a wave perceived by an observer moving relative to the wave source. It’s the reason a passing siren sounds higher-pitched as it approaches and lower-pitched as it recedes, and it’s a cornerstone of modern physics, engineering, and astronomy.

---

### 🔍 Core Intuition
- **Approaching source/observer**: Waves get "compressed" → higher frequency, shorter wavelength.
- **Receding source/observer**: Waves get "stretched" → lower frequency, longer wavelength.
- The effect depends on **relative motion along the line of sight** (radial velocity). Transverse motion causes only relativistic time-dilation effects.

---

### 📐 Mathematical Formulation

#### 1. **Classical Doppler Effect** (Mechanical Waves, e.g., Sound)
Requires a medium. The shift depends on velocities of source (`v_s`) and observer (`v_o`) relative to the medium, and wave speed `v`:
```
f' = f · (v ± v_o) / (v ∓ v_s)
```
- **Sign convention**: `+` in numerator when observer moves *toward* source; `−` in denominator when source moves *toward* observer.
- Example: Stationary observer, moving source: `f' = f · v / (v − v_s)` (approaching)

#### 2. **Relativistic Doppler Effect** (Electromagnetic Waves, Light)
No medium required. Depends only on relative velocity `v` between source and observer. Let `β = v/c`:
- **Approaching**: `f' = f · √[(1 + β) / (1 − β)]`
- **Receding**: `f' = f · √[(1 − β) / (1 + β)]`
- **Transverse** (90° motion): `f' = f / γ` (pure time dilation, `γ = 1/√(1−β²)`)

This causes **blueshift** (approach) and **redshift** (recession) in astronomy.

- The Doppler effect is a **spectral translation**: if `x(t)` has spectrum `X(f)`, a Doppler-shifted version has spectrum `X(f − Δf)`.

import numpy as np
import matplotlib.pyplot as plt

# 1. PHYSICAL CONSTANTS & PARAMETERS
# ==========================================
c = 3e8                # Speed of light (from Maxwell: c = 1/√(μ₀ε₀))
f0 = 24e9              # Carrier frequency (24 GHz radar band)
fs = 10e6              # Sampling frequency (10 MHz)
T = 1e-3               # Signal duration (1 ms)
t = np.arange(0, T, 1/fs)

# Target parameters
v_target = 30.0        # Target velocity (m/s) ~ 108 km/h
R0 = 100.0             # Initial range (meters)

# ==========================================
# 2. TRANSMITTED SIGNAL (Maxwell EM Wave)
# ==========================================
# Maxwell's equations guarantee this wave propagates at c in vacuum
tx_rf = np.cos(2 * np.pi * f0 * t)

# ==========================================
# 3. RECEIVED SIGNAL (Doppler + Delay)
# ==========================================
# Round-trip delay
tau = 2 * R0 / c
t_delayed = np.clip(t - tau, 0, T)

# Doppler shift: f_d = 2*v/c * f0 (radar round-trip factor of 2)
f_doppler = 2 * v_target / c * f0
rx_rf = np.cos(2 * np.pi * (f0 + f_doppler) * t_delayed)

# ==========================================

beat_raw = tx_rf * rx_rf

beat_baseband = lfilter(b, a, beat_raw)

### 🔍 How Each Concept Maps to the Code
| Concept | Where It Appears | Physical Role |
|---------|------------------|---------------|
| **Maxwell's Equations** | `c = 3e8`, wave propagation model | Guarantees EM waves travel at `c` in vacuum, satisfy wave equation `∇²E - (1/c²)∂²E/∂t² = 0` |
| **Doppler Effect** | `f_doppler = 2*v/c*f0`, `rx_rf` | Converts relative motion into measurable frequency shift (round-trip factor of 2 for radar) |
| **Fourier Analysis** | `np.fft.fft`, `f_est`, spectrum plot | Decomposes baseband signal into frequencies; peak at `f_d` reveals velocity |
