## Reminder: what “ON” means

| Mode | Env | Model path |
|------|-----|------------|
| baseline | all `MLX_REDLINE_*` unset | product `call_fn` only |
| redline_session | `MLX_REDLINE_DECODE=1` | product + session init |
| redline_sidecar | `DECODE=1` + `HSACO` + `SIDECAR=1` | product + **extra** retained-PM4 L=1 ticks |

Sidecar does **not** replace matmul/qmm. Expect ≈ same gen t/s, or slightly slower with sidecar.

## Interpretation

1. **35B gen is ~27–29 t/s** on this host — consistent with prior field notes (~26–31 t/s range), far below 0.8B’s ~115 t/s.  
2. **Session-only Redline ≈ baseline** (29.00 vs 29.15) — init cost is amortized; no model-path change.  
3. **Full sidecar ~2 t/s below first baseline**, but **within ~0.5 t/s of baseline2** (27.14 vs 27.60) — looks like **noise + small additive cost**, not a win.  
4. **No clear Redline speedup on 35B** with current sidecar design — same conclusion as 0.8B A/B.
